
# EVChargeFlow
## EV Charging Queue and Resource Allocation Decision Support System

### Project Engines
1. Engine 1 - Data and Integrity
2. Engine 2 - Logic and Rule
3. Engine 3 - Interface and Access
4. Engine 4 - Testing and Validation

### Technology Stack
- Backend: Java
- Frontend: React.js
- Database: To be finalized
- API: REST

### Project Objective
To manage EV charging requests, prioritize vehicles, allocate available chargers, manage reservations, and estimate waiting times.
